

## Текущая разработка сайта и Android

Сайт: https://graymans1on.github.io/university-notes/

Android-проект находится в `android/`; версия исходников — 1.0.3. Системные панели видимы, сохранены пять нижних разделов, закладки, чтение, виджеты и карта. Постоянные изменения с даты и разовые исключения хранятся отдельно в `content/schedule-overrides.json` и `content/schedule-exceptions.json`, сохраняя исходный двухнедельный цикл.

APK и отчёты проверок выдаёт GitHub Actions. Подписанный установочный файл и автоматический feed публикуются только при наличии исходного ключа; неподписанный артефакт явно обозначается и не пригоден для установки. Правила подписи — в `android/README.md`.

Актуальные правила материалов и технической поддержки: `MAINTENANCE.md`; публикация: `GITHUB_PAGES.md`; текущая админка и архив прежнего серверного проекта: `docs/ADMIN_ARCHITECTURE.md`.

В настройках доступен простой вход по коду администратора. Для общей публикации правок нужен собственный GitHub-токен с разрешением Contents: Read and write только для этого репозитория. Журналы дополняются, откат сохраняется отдельной записью. Подписанный APK 1.0.3 выдан владельцу файлом; автоматический APK-feed ожидает настройки секретов подписи в Actions.
