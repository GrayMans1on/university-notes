

## Текущая разработка сайта и Android

Сайт: https://graymans1on.github.io/university-notes/

Android-проект находится в `android/`; версия исходников — 1.1.1. Системные панели видимы, шесть нижних разделов: дисциплины, расписание, карта, учебники, закладки и настройки, закладки, чтение, виджеты и карта. Постоянные изменения с даты и разовые исключения хранятся отдельно в `content/schedule-overrides.json` и `content/schedule-exceptions.json`, сохраняя исходный двухнедельный цикл.

APK и отчёты проверок выдаёт GitHub Actions. Подписанный установочный файл и автоматический feed публикуются только при наличии исходного ключа; неподписанный артефакт явно обозначается и не пригоден для установки. Правила подписи — в `android/README.md`.

Актуальные правила материалов и технической поддержки: `MAINTENANCE.md`; публикация: `GITHUB_PAGES.md`; текущая админка и архив прежнего серверного проекта: `docs/ADMIN_ARCHITECTURE.md`.

В настройках доступен простой вход по коду администратора. Для общей публикации правок нужен собственный GitHub-токен с разрешением Contents: Read and write только для этого репозитория. Журналы дополняются, откат сохраняется отдельной записью. Подписанный APK 1.1.0 выдан владельцу файлом; автоматический APK-feed ожидает настройки секретов подписи в Actions.

В 1.1.0 добавлены выбор Wi-Fi/мобильной сети, офлайн-PDF и тематические диалоги выбора. В разделе [«Учебники»](https://graymans1on.github.io/university-notes/textbooks/) доступны четыре PDF с онлайн-открытием и отдельным сохранением офлайн; авторы и дисциплины указаны в каталоге `content/textbooks.json`. Сохранение общего расписания без пользовательского GitHub-токена ожидает отдельного согласования сервиса; проект описан в `docs/ADMIN_ARCHITECTURE.md`.

Для записи расписания по коду подготовлен сервис `service/schedule` и Android-мост 1.1.1. Worker пока не развёрнут из-за отсутствия доступа к Cloudflare и ключа GitHub App. Публичный URL сервиса оставлен пустым; прежняя запись по токену продолжает работать.


## Обновление 1.2.0 — дополнительные функции

Актуальная навигация Android: дисциплины, расписание, учебники, закладки, доп. функции, настройки. Карта находится внутри доп. функций. На сайте /tools/ объединяет новые редакторы и инструменты; личные данные сохраняются на устройстве. Полный состав, формат блок-схем, публикация объявлений и проверки описаны в docs/FEATURES_2026-10-24.md. Для файловых диалогов и перехода домашнего виджета в расписание требуется APK 1.2.0 с прежним сертификатом. Серверный компонент не добавляется.


## Последнее решение: инструменты только на сайте

Новые редакторы, калькулятор, графики и справочные карточки доступны отдельными пунктами бокового меню сайта. Преподаватели и объявления — только чтение; содержимое обновляется через рабочий чат. Android 1.2.1 возвращает интерфейс до инструментов и переход ближайшей пары на карту, сохраняя поиск дисциплин и пользовательские данные. Математические библиотеки и страницы инструментов исключены из APK и Android feed.


## Android 1.3.0 — текущая навигация

Нижнее меню: Дисциплины, Расписание, Инструменты, Учебники, Настройки. Карта и закладки находятся в Инструментах рядом с существующими редакторами и решателями сайта. Карточка ближайшей пары и виджет рабочего стола открывают расписание. Поиск дисциплин и пользовательские данные сохраняются. Расчёты и карта доступны офлайн; видео Manim открываются на сайте и не увеличивают APK. Новый нативный виджет и файловые диалоги требуют установки APK 1.3.0 поверх прежней версии с тем же сертификатом.
