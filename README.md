

## Текущая разработка сайта и Android

Сайт: https://graymans1on.github.io/university-notes/

Android-проект находится в `android/`; версия исходников — 1.0.2. Системные панели видимы, сохранены пять нижних разделов, закладки, чтение, виджеты и карта. Разовые изменения расписания отделены от постоянного двухнедельного цикла в `content/schedule-exceptions.json`.

APK и отчёты проверок выдаёт GitHub Actions. Подписанный установочный файл и автоматический feed публикуются только при наличии исходного ключа; неподписанный артефакт явно обозначается и не пригоден для установки. Правила подписи — в `android/README.md`.

Актуальные правила материалов и технической поддержки: `MAINTENANCE.md`; публикация: `GITHUB_PAGES.md`; проект защищённой админки для согласования: `docs/ADMIN_ARCHITECTURE.md`.
