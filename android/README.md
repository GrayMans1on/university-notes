# Учёба — Android

Минимальная версия Android: 8.0. Приложение включает текущие конспекты, задания, карту и расписание. Сайт продолжает развиваться из общих `content/` и `assets/`.

Внутри приложения: нижнее меню, ближайшая/текущая пара с фрагментом карты, продолжение чтения, закладки и настройки. На рабочий стол можно добавить виджеты «Расписание» (2×1, изменяемый размер) и «Ближайшая пара» (2×1, изменяемый размер).

Время расписания — Asia/Yekaterinburg. Обе недели и подгруппы учитываются. Идущая пара остаётся ближайшей до времени окончания. Виджеты обновляются по возможностям Android; в режиме энергосбережения возможна задержка.

Встроенные материалы открываются без интернета. Обновления идут только через проверенное подключение Wi-Fi. В открытом приложении проверка запускается при подключении, фоновую проверку планирует Android. Пакет применяют после проверки SHA-256 всех файлов. Старые материалы доступны до переключения; закладки и последняя тема хранятся отдельно.

Внешние ссылки (например, GitHub с лекциями по программированию) открываются в браузере и требуют интернета. Markdown сохраняется через системный диалог; PDF — через системную печать.

## Сборка

Требуются JDK 17, Gradle 8.9, Android SDK 35 и Python с CairoSVG 2.7.1.

```sh
npm ci
node scripts/build-notes.mjs
python3 scripts/prepare-android.py
gradle -p android assembleRelease testDebugUnitTest lintRelease
```

`android/local.properties` задаёт локальный `sdk.dir`; он не хранится в Git. APK: `android/app/build/outputs/apk/release/app-release-unsigned.apk`. Для установки APK необходимо подписать собственным закрытым ключом через `apksigner`. Закрытые ключи никогда не размещаются в репозитории.

После сборки сайта публикация GitHub Pages автоматически готовит обновляемую Android-копию и её контрольные суммы. Обновление самих Java-классов, разрешений и виджетов требует нового APK с той же подписью.

Проверка веб-интерфейса: `NODE_PATH=<путь к node_modules с jsdom> node android/tests/mobile.test.cjs`.

## Версия 1.0.1

Системные панели скрываются при запуске; внешняя Android-разметка резервирует безопасные области для панелей, вырезов и клавиатуры. Оба виджета тёмные, включая миниатюру карты. Виджет расписания по умолчанию 2×1; на большем размере появляется заголовок с датой. Лента сохраняет хронологию, показывает начало и конец пары, тип занятия и кабинет. Отступы между занятиями зависят от фактической длительности перерыва. При обновлении виджета текущая или ближайшая сегодняшняя пара автоматически попадает в центральную область; расписание можно прокручивать вручную.

После установки поверх версии 1.0.0 сохраняются настройки, закладки и история чтения. Размер уже размещённого виджета задаёт лаунчер: его можно уменьшить вручную или добавить заново для нового размера по умолчанию.

## Версия 1.0.2 — актуальные правила

Системные панели остаются видимыми, их области окрашиваются по теме. Пять основных нижних кнопок сохранены. Разовые изменения по дате, группе и времени поддержаны в карточках и виджетах; постоянное расписание не переписывается.

Приложение проверяет новый APK и скачивает его только по Wi-Fi. Перед установкой проверяет SHA-256, размер, пакет, версию и подпись. Кнопка установки открывает системный установщик с подтверждением пользователя. Для перехода с 1.0.1 нужна одна ручная установка APK с исходным ключом; не удаляйте приложение для обхода несовпадения подписи.

Workflow публикации собирает APK, запускает Java-тесты, lint и проверки веб-интерфейса. Артефакт `android-1.0.2` содержит подписанный `app.apk` при наличии исходных секретов подписи, иначе только `app-release-unsigned.apk` с пояснением. Неподписанный APK не устанавливается и не выдаётся приложению как обновление.

Для автоматической подписи требуются четыре секрета репозитория: `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`. Первоначальный закрытый ключ не восстановить из прежнего APK. Подмена ключа не выполняется.

Кнопка «Ввести код администратора» пока отключена: серверная архитектура в `docs/ADMIN_ARCHITECTURE.md` требует согласования владельца. Открытая проверка кода в JavaScript не используется.

## Постоянная подпись после переустановки

14 октября 2026 владелец разрешил новый ключ и удаление прежнего приложения. Новый установочный файл `university-notes-1.0.2.apk` подписан постоянным сертификатом SHA-256 `c2ae14afcf9d9343a8890c26016b309be15a3383e158f5ccdc398ecd9f390e38`. Проверка v2/v3 прошла.

Приватная резервная копия `university-notes-signing-backup.zip` хранится отдельно от GitHub и содержит исходный PKCS12-ключ и параметры. Для дальнейших выпусков используйте только этот ключ; закрытый архив не публикуется. После разовой переустановки последующие версии смогут обновлять приложение с этой подписью без удаления данных.

Подписанный APK выдан отдельным файлом. Для автоматической подписи в Actions всё ещё нужно записать четыре секрета, перечисленные выше; прежний артефакт Actions 1.0.2 остаётся неподписанным.


## Версия 1.0.3

В настройках работает вход по простому коду. Постоянные изменения с даты и разовые исключения редактируются отдельно, со своими историями и откатом. Для записи в GitHub вводится токен текущего сеанса с разрешением Contents: Read and write только для university-notes; он не сохраняется в приложении.

Нативный мост ограничен чтением расписания и записью двух журналов. Оба виджета учитывают постоянные правки и их дату начала. 1.0.3 подписывается сохранённым ключом и устанавливается поверх подписанной 1.0.2 без удаления данных. Код открывает функции устройства; серверные права записи определяет GitHub.


## Версия 1.1.0

Шесть отдельных разделов: Дисциплины, Расписание, Карта, Учебники, Закладки, Настройки. Ближайшая пара и продолжение чтения — в Дисциплинах, десять карточек компактны. Виджет и карточка текущей пары показывают время окончания.

В настройках выбирается Wi-Fi, Wi-Fi или мобильный интернет, либо только мобильный интернет. Это актуальное правило для всех встроенных сетевых функций вместо прежнего ограничения Wi-Fi.

Учебники перечисляются в content/textbooks.json. PDF скачиваются отдельно, проверяются и открываются встроенным просмотрщиком офлайн; они не входят в APK и не удаляются обновлением материалов. Select, даты и время открывают собственные диалоги в палитре приложения.

Требуется один новый APK 1.1.0 (versionCode 5), подписанный сохранённым ключом. Установка поверх подписанной 1.0.2/1.0.3 сохраняет данные. Запись расписания без токена пока требует согласования отдельного серверного посредника.


## Версия 1.1.1

Добавлен нативный запрос к сервису записи расписания. Адрес читается из обновляемого assets/schedule-service.json, допускается только HTTPS Worker /changes, перенаправления запрещены. Запрос соблюдает выбранный сетевой режим; код и черновик отправляются без GitHub-токена. При пустом URL продолжает работать прежний режим.

Сервис и клиент проверены на тестовом API, но Worker не развёрнут: нет доступа к Cloudflare и GitHub App. Нельзя объявлять общую запись по коду доступной до реального включения. Сборка требует прежнего ключа и versionCode 6; пользовательские данные не меняются.
