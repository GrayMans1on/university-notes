# Учёба — Android

Минимальная версия Android: 8.0. Приложение включает текущие конспекты, задания, карту и расписание. Сайт продолжает развиваться из общих `content/` и `assets/`.

Внутри приложения: нижнее меню, ближайшая/текущая пара с фрагментом карты, продолжение чтения, закладки и настройки. На рабочий стол можно добавить виджеты «Расписание» (4×2, изменяемый размер) и «Ближайшая пара» (2×1, изменяемый размер).

Время расписания — Asia/Yekaterinburg. Обе недели и подгруппы учитываются. Идущая пара остаётся ближайшей до времени окончания. Виджеты обновляются по возможностям Android; в режиме энергосбережения возможна задержка.

Встроенные материалы открываются без интернета. Обновления идут только через проверенное подключение Wi-Fi. В открытом приложении проверка запускается при подключении, фоновую проверку планирует Android. Пакет применяют после проверки SHA-256 всех файлов. Старые материалы доступны до переключения; закладки и последняя тема хранятся отдельно.

Внешние ссылки (например, GitHub с лекциями по программированию) открываются в браузере и требуют интернета. Markdown сохраняется через системный диалог; PDF — через системную печать.

## Сборка

Требуются JDK 17, Gradle 8.9, Android SDK 35 и Python с CairoSVG 2.7.1.

```sh
npm ci
node scripts/build-notes.mjs
python3 scripts/prepare-android.py
gradle -p android assembleRelease testDebugUnitTest lintRelease
```

`android/local.properties` задаёт локальный `sdk.dir`; он не хранится в Git. APK: `android/app/build/outputs/apk/release/app-release-unsigned.apk`. Для установки APK необходимо подписать собственным закрытым ключом через `apksigner`. Закрытые ключи никогда не размещаются в репозитории.

После сборки сайта публикация GitHub Pages автоматически готовит обновляемую Android-копию и её контрольные суммы. Обновление самих Java-классов, разрешений и виджетов требует нового APK с той же подписью.

Проверка веб-интерфейса: `NODE_PATH=<путь к node_modules с jsdom> node android/tests/mobile.test.cjs`.
