«Не могу не…» — **can’t help doing…**
:::example Can’t help с формой на -ing

Примеры: **can’t help loving / helping…**

:::

### Keep с формой на -ing

**Keep + глагол на -ing** означает продолжать или постоянно повторять действие. После *keeps* используется та же форма на *-ing*; окончание *-s* относится к *keep*.

Конструкция напоминает сочетание *can't help + -ing* по форме следующего глагола, но значение у неё другое: продолжение действия, а не невозможность удержаться.

### Компьютерная система: устройство и периферия

**A computer** — электронное устройство, которое принимает данные, обрабатывает их по инструкциям программы и выдаёт результат как информацию. Основные этапы: **input → processing → output**. **Storage** означает хранение данных и программ для дальнейшего использования.

**A computer system consists of hardware and software.** Компьютерная система включает физические компоненты и программное обеспечение.

| Термин | Определение на английском | Значение |
|---|---|---|
| hardware | the physical parts of a computer system | Физические компоненты компьютера |
| software | programs and instructions that tell a computer what to do | Программы и инструкции |
| central processing unit, CPU | the unit that executes program instructions and coordinates the other units | Центральный процессор; выполняет инструкции и координирует работу других устройств |
| main memory | memory that holds instructions and data currently being processed | Основная память: обрабатываемые данные и инструкции |
| peripherals | physical devices attached to a computer | Периферийные устройства: ввод, вывод и хранение |
| input | data and instructions entered into a computer | Вводимые данные и инструкции |
| output | the results produced by a computer | Результаты обработки |
| storage devices | devices used to store data and programs | Устройства хранения данных и программ |
| port | a socket into which an external device can be connected | Порт, разъём для подключения внешнего устройства |
| connector | the part of a cable that plugs into a port | Соединитель кабеля, штекер |

Процессор образно называют **the brain of the computer**. Основная память хранит инструкции и данные во время обработки, но не выполняет вычисления вместо процессора. В описании системы *main memory* представлена набором микросхем **RAM — random access memory**: название типа памяти и её роль в системе нужно различать.

#### Ввод, вывод и хранение

| Группа | Функция | Примеры |
|---|---|---|
| input devices | put data and instructions into the computer | keyboard, mouse, microphone, scanner, webcam |
| output devices | present processed information in a form the user can understand | monitor, printer, speakers, headphones |
| storage devices | store data and programs | hard drive, flash drive, optical discs |

**A mouse is a pointing device and an input device.** Указательное устройство относится к вводу. Микрофон тоже вводит данные, а наушники выводят звук. **A headset** — гарнитура, объединяющая наушники и микрофон, поэтому её части выполняют разные функции.

**A hard drive / hard disk** — накопитель с магнитным способом хранения. **A disk drive** — устройство для чтения дисков, а для подходящих носителей и приводов — также для записи. Не путать носитель, привод и порт подключения.

Облачное хранилище, например iCloud, — сервис, а не отдельное физическое периферийное устройство пользователя. Из названия сервиса нельзя определить доступный объём хранения; ёмкость конкретного накопителя указывается в его характеристиках.

| **laptop / notebook PC** | Переносной компьютер со встроенными экраном, клавиатурой и **touchpad**. Имеет аккумулятор и варианты подключения периферии |
| **tablet PC** | В рассматриваемом типе устройства предусмотрены сенсорный экран и цифровое перо; возможны поворот экрана, отсоединяемая клавиатура, распознавание рукописного текста и голоса |
| **personal digital assistant, PDA** | Небольшое карманное устройство: заметки, напоминания, адреса и вычисления; в описанных моделях также телефонные и сетевые возможности. **Handheld, palmtop, pocket PC** — связанные обозначения карманных устройств |
| **wearable computer** | Компьютер, носимый на теле или одежде, например на поясе, в жилете или рюкзаке. Работает от батареи, рассчитан на мобильную работу, в том числе **hands-free** |

Характеристики относятся к типам и моделям из учебного текста. **A laptop can be as powerful as a desktop PC** означает возможность сопоставимой производительности, а не равенство любых двух компьютеров.
