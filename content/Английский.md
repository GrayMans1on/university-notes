# Английский

## Грамматика

### Конструкция can’t help

«Не могу не…» — **can’t help doing…**
:::example Can’t help с формой на -ing

Примеры: **can’t help loving / helping…**

:::

### Keep с формой на -ing

**Keep + глагол на -ing** означает продолжать или постоянно повторять действие. После *keeps* используется та же форма на *-ing*; окончание *-s* относится к *keep*.

Конструкция напоминает сочетание *can't help + -ing* по форме следующего глагола, но значение у неё другое: продолжение действия, а не невозможность удержаться.

### Пунктуация и относительные предложения

**Знаки препинания:**

| Английское название | Значение | Знак |
|---|---|---|
| full stop | Точка в конце предложения | . |
| colon | Двоеточие | : |
| semicolon | Точка с запятой | ; |
| dash | Тире | — |
| parentheses | Круглые скобки | ( ) |
| brackets | Квадратные скобки | [ ] |
| curly brackets / braces | Фигурные скобки | { } |
| quotation marks | Кавычки | “ ” |
| comma | Запятая | , |
| ellipsis | Многоточие | … |
| exclamation mark | Восклицательный знак | ! |
| question mark | Вопросительный знак | ? |
| period | Точка в десятичном числе, пример 0.1 | . |
| hyphen | Дефис | - |

*Period* также используется в американском английском для точки в конце предложения.

**Правило:** перед *that* запятая не ставится.

*To twig* — уловить суть в чём-то.  
*To cotton on* — «въехать в тему».

:::example Двоеточие перед перечислением

> There are a lot of types of devices: a smartphone, a laptop, and a PC.

:::

:::example Относительные предложения с which

**Примеры с which:**

> We went to the lake, which was very stormy that day.

«Мы пошли к озеру, которое в тот день было бурным». Запятая отделяет дополнительное сообщение об озере.

> He didn't see the letters which were lying on the table.

Пояснение: «Он не видел писем → каких? → которые лежали на столе».

:::

#### Проблемы использования технологий

- **Technological dependence** — технологическая зависимость.
- **Web addiction** — интернет-зависимость.
- **Electronic waste** — электронные отходы.
- **Cybercrime** — киберпреступность.
- **Loss of privacy** — утрата приватности.
