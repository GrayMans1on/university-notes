Существующие учебные материалы не сокращались. Ниже зафиксированы значимые ошибки и неоднозначности новой пачки, которые не переносились буквально.

|---|---|
| Семейные отношения: порядок `S∘R` используется для тёти, хотя сначала идёт сестра, затем мать | По единому соглашению проекта первым выполняется левое отношение: тётя по матери — `R∘S`; `S∘S` — бабушка по матери |
| Семейный пример `S⁻¹∘R⁻¹` назван племянником | При левом первом порядке такой вывод неверен. Для ребёнка брата используются `R⁻¹∘S` и, с иными половыми условиями, `R⁻¹∘S⁻¹`. Направления и формальные условия разобраны явно |
| «Родитель ∘ брат = родитель» без условия | Требуется используемая в задаче модель братьев с общими родителями; в общем случае неполнородных братьев вывод не автоматический |

| Лемма: удаляемый a выражается через элементы A, без запрета использовать a | Добавлено существенное `aᵢ ∈ A\{a}`; иначе тождество a=a дало бы ложный вывод |
