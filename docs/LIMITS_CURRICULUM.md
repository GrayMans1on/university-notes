- Подпоследовательности и частичные пределы
- Вычисление пределов последовательностей
- Предел функции по Коши и Гейне
- Свойства конечного предела функции

## Разрешённые методы решения

| Метод | Тема в конспекте |
|---|---|
| Подстановка, арифметические свойства, область определения | Свойства конечного предела функции; Непрерывность и точки разрыва |
| Сокращение, общий знаменатель, выделение множителей | Вычисление пределов функций |
| Старшие степени, сопряжённые квадратные/кубические корни | Вычисление пределов последовательностей; Вычисление пределов функций |
| Первый замечательный предел, стандартные следствия, перенос точки в ноль | Первый замечательный предел и замены переменных |
| Основание 1+u, произведение u·v, второй замечательный предел | Число e и второй замечательный предел |
| Логарифмы ≪ степени ≪ экспоненты ≪ факториалы ≪ nⁿ; раскрытие факториалов | Вычисление пределов последовательностей |
| Зажатая функция, ограниченный множитель, разные подпоследовательности | Свойства конечного предела функции; Подпоследовательности и частичные пределы |
| Знаки слева/справа, модуль, целая часть | Вычисление пределов функций; Целая часть, промежутки и окрестности |

## Запрещённые подмены

Правило Лопиталя, разложения Тейлора/Маклорена, формальные степенные ряды и численное угадывание не разрешены. Наличие таблицы производных не даёт права использовать производные для неопределённости 0/0. Стандартные пределы применяются с проверкой стремления внутреннего аргумента к нулю, а не как неограниченная серия.

Произвольный ввод не означает таблицу заготовленных ответов. Проверки используют примеры курса и новые выражения с изменёнными числами/аргументами. Если алгоритм не завершил решение, показывается «Не удалось решить изученными методами» с причиной. Не утверждать, что задача не проходилась, только потому что алгоритм её не распознал. Отдельно помечать конструкции вне реализованного языка ввода. Не обещать универсальность по конечному набору тестов.

## Оформление

Единая запись: lim, под ним переменная и редактируемая точка/направление, справа математическое поле выражения. Результат и последовательные шаги ниже, с формулами преобразований, проверками условий и ссылками на использованные темы. Показывать одно решение общего предела без выбора стороны и без отдельных левого/правого разборов. Внутри проверять обе стороны и область определения; при несовпадении сообщать об отсутствии общего предела. Старые .csulimit/version 1 открываются, неизвестные/ошибочные файлы не заменяют работу.


## Порядок выбора метода

1. Проверить прямую подстановку и непрерывность всех исходных подвыражений; если она допустима, дать ответ без замены переменной.
2. При неопределённости выделить подходящее стандартное отношение и рациональный множитель в исходной переменной. Для составных выражений применить арифметические свойства к уже найденным конечным пределам частей.
3. Если простые методы не завершили разбор, использовать существующие точные алгебраические преобразования, сопряжённое, шкалу роста и необходимые замены. Не выдавать неудачу алгоритма за отсутствие метода в программе.
