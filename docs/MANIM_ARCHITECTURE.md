# Manim: опубликованный вариант и граница следующего этапа

## Реализовано на GitHub Pages

- Общий решатель выдаёт проверенную цепочку `chain`; видеосцена получает именно её.
- GitHub Actions собирает шесть примеров в двух палитрах. Реальные MP4 и каталог публикуются в Pages; исходные видео не входят в Git, APK или обновление материалов Android.
- Плеер подбирает ролик по каноническому выражению, точке и переменной. Другой коэффициент не получает чужое видео. Фон и текст соответствуют палитре панели сайта.
- Для завершённого произвольного решения экспортируется самостоятельная сцена `limit-animation.py`, которую можно отрендерить установленным Manim. Экспорт сцены не является готовым видео.

## Что требуется для MP4 любого введённого предела

Предлагаемая архитектура: отдельный контейнер с очередью заданий, Node.js-решателем из этого репозитория и Python/Manim. Сайт остаётся на Pages и обращается к явно настроенному HTTPS API.

1. Пользователь нажимает «Собрать видео». Только тогда отправляются выражение, точка, числовые параметры и тема. Заметки, учебные документы и данные Android не отправляются.
2. API проверяет размеры и язык ввода, заново решает предел тем же движком. Клиент не передаёт исполняемый Python или произвольный TeX.
3. Очередь получает сериализованную проверенную цепочку. Фиксированная сцена Manim создаёт MP4 в изолированном задании с лимитом времени и ресурсов.
4. Сайт показывает ход выполнения и затем штатный плеер/скачивание. Простая пользовательская авторизация для обычного просмотра не требуется; ограничение частоты запросов работает на стороне сервиса.
5. Повторное одинаковое решение использует кэш по версии движка, формуле, точке, параметрам, теме и разрешению. Срок и размер временного кэша задаются отдельно; учебные материалы и личные документы не затрагиваются.

Этот сервис не развёрнут. Нужны согласие владельца на отдельный вычислительный компонент, выбор хостинга и доступ для размещения. GitHub Pages сам Python не исполняет; публичного секрета или токена GitHub для посетителей в JavaScript нет.
